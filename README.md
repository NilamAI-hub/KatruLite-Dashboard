# KatrU Lite

## AI + IoT Enabled Environmental Monitoring System

KatrU Lite is an intelligent environmental monitoring platform designed to improve sanitation, occupational safety, and public health by continuously monitoring air quality and hazardous gases.

---

## Features

- Live Environmental Dashboard
- Public Toilet Monitoring
- Industrial Factory Monitoring
- Community Toilet Monitoring
- School Monitoring
- Hospital Monitoring
- STP Monitoring
- AI Recommendations
- Environmental Health Score
- SMS Alert Preview
- Live Charts
- Threshold Configuration
- Automatic Alert Generation
- Historical Analysis
- Device Monitoring
- Responsive Dashboard

---
